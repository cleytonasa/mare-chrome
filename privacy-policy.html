Política de Privacidade — Maré Brasil (Tábua de Marés)

Última atualização: 13 de setembro de 2026

Esta Política de Privacidade descreve como a extensão Maré Brasil - Tábua de Marés ("a Extensão") trata os dados dos usuários.

1. Coleta de dados

A Extensão não coleta, não armazena remotamente e não transmite nenhum dado pessoal, de navegação ou de identificação do usuário. Não há servidores próprios recebendo informações dos usuários da Extensão.

2. Dados armazenados localmente

A Extensão utiliza a permissão storage do navegador exclusivamente para salvar, no dispositivo do próprio usuário (via chrome.storage.local), o identificador do porto/estação de maré selecionado por último. Essa informação:

  • fica armazenada apenas localmente, no navegador do usuário;
  • nunca é enviada para servidores externos ou terceiros;
  • não contém dados pessoais identificáveis;
  • pode ser apagada a qualquer momento removendo a extensão ou limpando os dados de navegação.

3. Código remoto

A Extensão não carrega nem executa código remoto. Todo o HTML, CSS e JavaScript utilizados estão empacotados dentro da própria extensão. Os cálculos de maré são realizados localmente, no navegador do usuário, com base em constantes harmônicas já embutidas na Extensão.

4. Compartilhamento de dados com terceiros

A Extensão não compartilha, vende ou transfere qualquer dado a terceiros, pois não coleta dados em primeiro lugar.

5. Rastreamento e analytics

A Extensão não utiliza cookies, pixels de rastreamento, ferramentas de analytics ou qualquer mecanismo de rastreamento do comportamento do usuário.

6. Alterações nesta política

Caso esta política seja atualizada, a nova versão será publicada nesta mesma página, com a data de atualização revisada no topo.

7. Contato

Em caso de dúvidas sobre esta Política de Privacidade, entre em contato pelo repositório do projeto: github.com/cleytonasa/mares.
